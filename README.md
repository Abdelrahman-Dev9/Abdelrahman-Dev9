<summary><b>SETUP — self-host stats (recommended)</b></summary>

The public `github-readme-stats` instance often hits rate limits. Self-host once (~20 min):

1. Create a **classic** GitHub token (`repo` scope, no expiration) at https://github.com/settings/tokens — copy it immediately; never commit it.
2. Fork https://github.com/anuraghazra/github-readme-stats
3. Deploy the fork on [Vercel](https://vercel.com) (Hobby) with env var `PAT_1` = your token.
4. Replace `github-readme-stats.vercel.app` in this README with `your-instance.vercel.app`.

Also ensure this repo → **Settings → Actions → General → Workflow permissions → Read and write**, then run **Generate Snake Animation** once so the `output` branch exists.

</details>
